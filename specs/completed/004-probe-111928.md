# Probe endpoint for the cluster ship path

## Problem

The cluster ship path (Route D) has no end-to-end probe. Every run so far has
been a real feature, so a failure in the pipeline is indistinguishable from a
failure in the feature.

## Goal

Add a `/probe` HTTP endpoint to the service that returns `200 OK` with the body
`ok`. It exists only to be shipped through the pipeline.

## Proof

`curl -s -o /dev/null -w '%{http_code}' http://localhost:<port>/probe` prints
`200`, and the response body is `ok`.

## Must not change

Existing routes, their status codes, and the service's startup behaviour.
